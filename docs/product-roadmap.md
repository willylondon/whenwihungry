# When Wi Hungry Product Roadmap

## Platform Direction

When Wi Hungry should grow into a restaurant recommendation platform with an editorial voice.

- Visitors can browse restaurants, read official When Wi Hungry reviews, and see public ratings/comments.
- Signed-in users can submit restaurant listings, leave comments, and add 1-5 star ratings.
- Only the When Wi Hungry admin can publish blog-style editorial reviews.
- Restaurants become more recommended through a weighted mix of star ratings, comment quality/sentiment, review count, recency, and official WWH approval.

## Future CMS

Add Sveltia CMS later for smooth editing of:

- Official blog-style reviews
- Restaurant profiles
- Categories
- SEO titles/descriptions
- Featured placements
- Review images

The CMS should not replace public user actions. Public submissions, comments, and ratings belong in Supabase.
